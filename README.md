## 🚀 Features

- **Hero Section** — Introduction with key stats and tech stack chips
- **About** — Background, focus areas, and areas of interest
- **Skills** — Animated skill bars across 4 security domains
- **Projects** — Showcase of real GitHub security projects
- **Certifications** — Gallery of all 6 certificates with lightbox modal viewer
- **Resume** — Education, training history, and CV download
- **Contact** — Working contact form powered by Formspree + social links
- Fully **responsive** — works on mobile, tablet, and desktop
- **Smooth scroll animations** and fade-in effects
